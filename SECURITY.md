# Security Policy

## Supported Versions

`@w6w/ui` is not published to npm (see the README's
[Install / consume](README.md#install--consume) section) and carries no versioned release line.
The **latest `main`** is the only supported version — there is nothing older to backport a fix to.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

Report it privately to **legal@w6w.io**. Include:

- A description of the issue and its potential impact.
- Steps to reproduce, or a proof-of-concept if you have one.
- The affected commit or version, if known.

We don't currently commit to a fixed response-time SLA, run a bug bounty program, or claim a
completed third-party security audit — if you're evaluating this component library for a
security-sensitive use, treat that as the honest state of things rather than an implied guarantee.
We do read every report sent to the address above and will follow up.

Please give us a reasonable window to investigate and, where applicable, ship a fix before any
public disclosure.
